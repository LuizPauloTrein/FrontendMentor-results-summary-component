# 📊 Results Summary Component

Projeto desenvolvido como parte de um desafio do Frontend Mentor.

## 📌 Sobre o projeto

Este projeto consiste em um componente de resumo de resultados, exibindo a pontuação geral e um detalhamento por categorias (Reaction, Memory, Verbal e Visual).

O objetivo principal foi praticar layout moderno com Flexbox, organização de arquivos CSS e construção de um layout responsivo baseado em design fornecido pelo desafio.

---

## 🚀 Tecnologias utilizadas

- HTML5
- CSS3
- Flexbox
- Variáveis CSS
- Media Queries (Responsividade)
- Google Fonts

---

## 🎯 O que eu pratiquei

- Estruturação semântica utilizando `<main>`, `<section>`, `<h1>`, `<h2>` e `<p>`
- Organização de arquivos CSS (reset, variables, style, responsive)
- Uso de variáveis CSS para padronização de cores
- Criação de layout em duas colunas com Flexbox
- Estilização de cards de categorias com cores diferentes
- Implementação de responsividade para telas menores
- Importação e utilização de fontes do Google Fonts
